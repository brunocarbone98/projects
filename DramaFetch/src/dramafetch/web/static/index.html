DramaFetch

Download the TikTok short-drama episodes your account can already watch, a whole series at a time, for personal offline viewing.

Access token

A session cookie (HttpOnly, 30 days) remembers it; the page itself stores nothing.

1. Series

The long number is the series id; the trailing number is only the episode you were watching. Resolving opens TikTok in a browser on this machine and usually takes 10–40 s; the list is kept for 15 minutes, so downloading right after it costs no second visit (Refresh list fetches it again). Then Download all free is one click, and every episode it downloads gets a Save link for this device. Covers are embedded in the video by default (serve --thumbnail both saves a separate image as well); the Cover link gives you the embedded one, or the file saved next to the video.
