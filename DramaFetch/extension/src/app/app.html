      Settings

      A JSON file in Downloads/DramaFetch/reports: for each episode that did not download, its status, message, probable cause, the requests made (hosts, HTTP statuses, sizes) and the list entry TikTok served to your session — never your cookies.

      A notification from Chrome as each drama a download finishes: downloaded, or the episodes to retry, with a Retry button. None shows? Allow Chrome's notifications in Windows (Settings → System → Notifications) and check that Focus assist (Do not disturb) is off.

      When a drama's download ends with episodes that did not download for a reason a retry can change — a cut transfer, a file that failed its check, a network error —, DramaFetch queues one retry of them, the same as pressing Retry: the rest between downloads, a fresh list, the usual pauses. Never after TikTok refused a request, during the 30-minute cooldown or after a stop, and never for locked, DRM-protected or short-served episodes.

      File names may use {series}, {number}, {n}, {title} and {id}. Pauses may only be made longer than the defaults (4–9 s between episodes, 60–120 s every 10): faster is never safe against TikTok.
